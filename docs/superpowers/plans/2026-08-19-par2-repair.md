# PAR2 Streaming Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Background PAR2 repair of missing usenet articles: streams the recovery set from NNTP, solves GF(2^16) Reed–Solomon, persists repaired article payloads to a local patch store, and serves them on the hole branch of the read path.

**Architecture:** New `internal/par2repair` package (planner, solver, patch store, job, service/queue) + extended `internal/importer/parser/par2` packet parsing + one new branch in the usenet reader's hole path. Triggered from playback holes, health-check degraded verdicts, and a manual API endpoint. Spec: `docs/superpowers/specs/2026-08-19-par2-repair-design.md`.

**Tech Stack:** Go, `github.com/akalin/gopar/gf2p16` (GF(2^16) math, already in go.mod), SQLite/Postgres migrations, existing fakepool/nzbbuild/par2gen test harnesses.

## Global Constraints

- Repair NEVER blocks or slows a read; the hot path gains no work — only the already-cold hole branch gains one lookup.
- Repair sweep uses the pool's **normal lane** gated by `pool.Manager.AcquireImportConnection` (same as imports).
- Memory during a job ≤ `max_memory_mb` (default 256): k accumulators of slice_size + k×k matrix. Never release-sized.
- A recovered slice failing its IFSC MD5 aborts the job; nothing unverified is ever stored.
- Patch writes are atomic (tmp + rename): readers see a miss or a complete verified payload, never partial data.
- Effective repair cap = min(`max_repair_ratio` × file bytes, recovery slices available, memory budget).
- Naming: this feature is `par2repair` everywhere ("repair" alone already means ARR repair in this codebase).
- All commits: Conventional Commits format. Run `go test -race` for packages you touch. `make` must pass before the final task completes.
- PAR2 packet layouts (spec v2.0, all integers little-endian):
  - Header (64 B): magic `PAR2\0PKT` (8) | length u64 (8) | packet MD5 (16) | RecoverySetID (16) | type (16). Packet MD5 = MD5 of bytes 32..length.
  - Main body: slice_size u64 | numRecoveryFiles u32 | numRecoveryFiles×FileID (16 each) | trailing non-recovery FileIDs.
  - IFSC body: FileID (16) | N×{sliceMD5 (16) | sliceCRC32 u32} where N = (bodyLen−16)/20.
  - RecvSlic body: exponent u32 | slice_size bytes of recovery data.
  - FileID = MD5(hash16k ‖ length u64 LE ‖ name bytes). Recovery-set files are ordered by FileID ascending (byte-wise). Slice checksums are over the slice zero-padded to slice_size.
- RS math (PAR2 Vandermonde): input slice with global index j has base g_j = the j-th element of {2^i in GF(2^16) : i = 0..65534, i % 3 ≠ 0, i % 5 ≠ 0, i % 17 ≠ 0, i % 257 ≠ 0}. Recovery slice with exponent e equals Σ_j g_j^e × D_j. Fold with `gf2p16.MulAndAddByteSliceLE` (XOR-accumulate) and `gf2p16.MulByteSliceLE`; solve k×k with `gf2p16.Matrix.Inverse()` (may fail — the PAR2 matrix is flawed; retry with a different recovery-slice subset, then give up as unrepairable).

func buildRecovery(slices [][]byte, exps []uint32, sliceSize int) [][]byte {
    out := make([][]byte, len(exps))
    for i, e := range exps {
        acc := make([]byte, sliceSize)
        for j, sl := range slices {

```go
// internal/par2repair/solver.go
package par2repair

// Accumulator math: recovery slice r (exponent e_r) satisfies
//   R_r = Σ_{j present} g_j^{e_r} D_j  ⊕  Σ_{m missing} g_m^{e_r} D_m
// Seed acc_r with R_r, fold every present slice into it; what remains is the
// missing-only linear combination. Solve the k×k system A x = acc with
// A[r][i] = g_{missing[i]}^{e_r} via Matrix.Inverse.

func NewSolver(missingIdx []int, recoveryExp []uint32, sliceSize int) (*Solver, error) {
    if len(missingIdx) != len(recoveryExp) || len(missingIdx) == 0 {
        return nil, fmt.Errorf("par2repair: need exactly one recovery slice per missing slice (missing=%d recovery=%d)", len(missingIdx), len(recoveryExp))
    }
    if sliceSize <= 0 || sliceSize%4 != 0 {
        return nil, fmt.Errorf("par2repair: invalid slice size %d", sliceSize)
    }
    acc := make([][]byte, len(missingIdx))
    for i := range acc {
        acc[i] = make([]byte, sliceSize)
    }
    return &Solver{missing: slices.Clone(missingIdx), exps: slices.Clone(recoveryExp), acc: acc}, nil
}

func (s *Solver) AddRecovery(i int, payload []byte) {
    // XOR payload into acc[i]: implemented as MulAndAdd with coefficient 1.
    gf2p16.MulAndAddByteSliceLE(1, payload, s.acc[i])
}

func (s *Solver) FoldPresent(globalIdx int, slice []byte) {
    g := VandermondeBase(globalIdx)
    for r := range s.acc {
        gf2p16.MulAndAddByteSliceLE(g.Pow(s.exps[r]), slice, s.acc[r])
    }
}

func (s *Solver) Solve() ([][]byte, error) {
    k := len(s.missing)
    a := gf2p16.NewMatrixFromFunction(k, k, func(r, i int) gf2p16.T {
        return VandermondeBase(s.missing[i]).Pow(s.exps[r])
    })
    inv, err := a.Inverse()
    if err != nil {
        return nil, ErrSingularMatrix
    }
    out := make([][]byte, k)
    for i := range out {
        out[i] = make([]byte, len(s.acc[0]))
        gf2p16.MulByteSliceLE(inv.At(i, 0), s.acc[0], out[i])
        for r := 1; r < k; r++ {
            gf2p16.MulAndAddByteSliceLE(inv.At(i, r), s.acc[r], out[i])
        }
    }
    return out, nil
}

// VandermondeBase caches the generator sequence lazily (sync.Once, grow-on-
// demand slice): 2^i for i = 0.. skipping i%3==0 || i%5==0 || i%17==0 || i%257==0.
```

Note: `FoldPresent` and `AddRecovery` are called from a single job goroutine — no locking (document this).

Logic:
1. Order `files` to match `idx.RecoveryIDs` (error if a set member is absent from `files` — the caller failed to resolve it).
2. `startSlice[f] = Σ ceil(files[<f].Length / SliceSize)`; `GlobalSlices` = total.
3. For every dead article: file byte range `[FileStart, FileStart+Size)` → global slices `startSlice[f] + FileStart/S` .. `startSlice[f] + (FileStart+Size-1)/S`. Union + sort = `Missing`.
4. Caps: damaged bytes = `len(Missing) × SliceSize`. Ratio check against **the damaged files' total bytes** (`Σ Length of files containing missing slices`) — mirrors the holes cap which is per-file. Memory check: `len(Missing) × SliceSize > MaxMemoryBytes` → `ErrUnrepairable`. Wrap with reason: `fmt.Errorf("%w: needs %d recovery slices, set has %d", ErrUnrepairable, k, len(idx.Recovery))` etc.
5. Choose the k lowest-exponent recovery refs; remainder becomes `SpareRecovery`.

Algorithm (single goroutine for the fold; prefetch articles with a small worker pool of `fetchConcurrency = 4` feeding an ordered channel):

1. Build `missingSet := map[int]bool` from `plan.Missing`.
2. **Recovery payloads first** (they're small): for each `plan.Recovery[i]`, locate its par2 stream articles covering `[BodyOffset, BodyOffset+SliceSize)`, fetch, slice out payload, `solver.AddRecovery(i, payload)`. On a dead recovery article: swap in a `SpareRecovery` ref and rebuild the solver (recompute exponents) — up to `len(SpareRecovery)` swaps, else `ErrUnrepairable`.
3. **Sweep**: `global := 0`; for each `plan.Files` in order: stream its articles in order, maintaining a `sliceBuf := make([]byte, SliceSize)` fill cursor and a `sliceDirty bool` (touched by a dead article). Dead article → advance cursor by its size zero-filling, mark affected slices dirty. On each completed slice (or final partial slice → zero-pad):
   - if `missingSet[global]` (equivalently dirty): skip fold.
   - else: verify CRC32 against `idx.SliceChecks[fileID][localSlice].CRC32`; mismatch → treat as newly-missing: **return `ErrUnrepairable`** in the prototype with a clear message ("present slice failed checksum; replan not implemented") — logged; replan is a documented follow-up.
   - fold: `solver.FoldPresent(global, sliceBuf)`.
   - `global++`.
4. `out, err := solver.Solve()`; `ErrSingularMatrix` → swap one recovery ref for a spare, redo from step 2 (bounded retries — this means recovery payload re-fetch AND re-sweep; log the cost).
5. Verify each `out[i]` MD5 against IFSC. Mismatch → `ErrUnrepairable`.
6. For each `plan.DeadArticles`: assemble its payload from the recovered slices (slice-relative offsets computed from `FileStart`/`Size`/`SliceSize`; edge slices may contribute partial ranges), `store.Put(messageID, payload)`.

`fetch.go`: `PoolFetcher.Fetch` = `budget.AcquireImportConnection(ctx)` → `client.Body(ctx, messageID)` → read all → release. Wrap errors.
